# Screenshots

This folder contains screenshots of the AccessIQ application for documentation purposes.

## Available Screenshots

- Architecture overview
- Dashboard
- Request flow
- Admin panel
- API documentation (Swagger UI)

## Usage

Screenshots are referenced in the documentation files:
- `docs/Architecture.md`
- `docs/Deployment.md`

## Guidelines

- Use PNG format for screenshots
- Name files descriptively (e.g., `dashboard-overview.png`)
- Keep file sizes reasonable (< 2MB each)
- Update screenshots when UI changes
